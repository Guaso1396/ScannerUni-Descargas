# ScannerUni — Descargar

Escáner de documentos para Android, **sin anuncios**.

## 📥 Descargar

**[Descargar ScannerUni.apk (versión 1.0)](https://github.com/Guaso1396/ScannerUni-Descargas/raw/main/ScannerUni.apk)**

Requiere Android 7.0 o superior.

## Cómo instalar

1. Toca el enlace de arriba desde el celular y descarga `ScannerUni.apk`.
2. Abre el archivo descargado.
3. Si Android lo pide, permite **«Instalar apps desconocidas»** para el navegador o el explorador de archivos.
4. Toca **Instalar**.

## Qué hace

- Escanea con la cámara del teléfono o trae imágenes de la galería y archivos.
- Recorte inteligente y filtros para que las fotos queden bonitas.
- Carné por lado y lado (C.C., T.I., carné universitario): los dos lados en una sola hoja.
- PDF tamaño Carta u Oficio automático, PDF con contraseña, exportar a JPG o PNG.
- Compartir por WhatsApp, Gmail, Drive y cualquier app.
- Carpetas, marca de agua y texto (OCR).
